# AI 简历优化助手 (AI Resume Optimizer)

## 📖 项目简介
这是一个基于 Python + Streamlit + 智谱 GLM-4 大模型开发的在线简历优化工具。

## ✨ 核心功能
- **多格式支持**：支持上传 `.txt`、`.pdf`、`.docx` 格式的简历文件。
- **HR 视角深度润色**：内置 10 年经验 HR System Prompt，使用 STAR 法则将大白话改写为专业职场表述。
- **极速响应**：调用智谱云端大模型，秒出优化结果。
- **安全合规**：API Key 存储于 Streamlit Secrets，代码开源无泄露风险。
